## How it works

Utilizando 4 bits como entradas representadas como switchs, se simulan los numeros 0-9.

Se utiliza para representar esto un display de 7 segmentos (a,b,c,d,e,f,g)

Using a 4 inputs DIP Switch we are representing 4 inputs (4 bits), we are gonna simulate the sequence 0-9

Will use a 7 segments display

## How to test

El proyecto unicamente requiere ser inicializado e interactuar con las entradas 0-3, representando en binario los numeros de 0 al 9, y estos mismos se representaran en el display

The project only needs to be initalized and that the user interacts with the inputs 0-3, to visualize the numbers from 0 to 9 in the 7 segment display
## External hardware

Display de 7 segmentos de catodo comun, DIP switch de 4 entradas.
